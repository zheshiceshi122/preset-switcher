# 预设切换器

SillyTavern 本地扩展，用于给不同角色卡绑定 OpenAI / 聊天补全预设，并在不改写酒馆原预设的前提下，为每张角色卡维护自己的预设副本。

## 能做什么

- **按角色卡绑定预设：** 从酒馆已有的 OpenAI / 聊天补全预设中选择要绑定的项目。绑定关系保存在当前角色卡上；悬浮球只列出当前角色卡绑定过的项目。
- **保存角色专属副本：** 绑定时会把酒馆预设复制到角色卡数据。之后修改副本、切换副本、添加备注、复制副本，都不会直接改写酒馆原预设。
- **为一个原预设创建多个版本：** 同一张角色卡可复制某个已绑定项目，分别设置名称、备注和条目内容。例如保留“日常版”和“严肃版”；其他角色卡也可以拥有各自独立的副本。
- **备注作为主要标题：** 填了备注时，列表以备注作主标题、酒馆原预设名作副标题；没有备注时，原预设名就是主标题。复制副本时也可直接填写备注。
- **悬浮球切换：** 点击悬浮球打开列表，再点某个已绑定副本的切换按钮。当前正在使用的副本会标为“当前使用中”。没有绑定的酒馆预设不会出现在这里，也不能从悬浮球切换。

## 界面组成

- **悬浮球：** 固定在聊天页面上，可拖动并在靠近屏幕左右边缘时半隐藏。点击后打开当前角色卡的预设面板。
- **预设面板：** 完整模式下查看绑定列表、当前使用状态和同步状态，并执行切换、编辑、复制、备注、同步或解绑。底部可绑定酒馆现有预设。快速模式会收起管理操作，只保留当前角色和预设切换入口。
- **条目编辑器：** 通过搜索和分页浏览副本里的提示词，星标收藏常用条目；在列表直接勾选启用状态，点击名称进入表单修改内容。保存范围仅限当前角色卡的当前副本。
- **外观设置弹窗：** 从预设面板右上角打开，设置悬浮球大小、图片、完整 / 快速显示模式，以及切换时是否保留当前 API 连接设置。

## 安装与开始使用

### 通过酒馆安装

1. 在酒馆中打开“扩展程序”，点击“安装扩展”。
2. 输入仓库地址 `https://github.com/zheshiceshi122/preset-switcher`，完成安装。
3. 确认“预设切换器”已启用，刷新页面，然后打开角色卡聊天。

### 手动安装

1. 将整个 `预设切换器` 文件夹复制到当前 SillyTavern 用户目录下的 `extensions/preset-switcher`。目标目录中应直接包含 `index.js`、`style.css` 和 `manifest.json`。
2. 在酒馆的“扩展程序 / 管理扩展”中启用“预设切换器”，然后刷新酒馆页面。
3. 打开一张角色卡的聊天，使用页面上的小悬浮球打开切换器。
4. 在面板底部选择酒馆已有的 OpenAI / 聊天补全预设，点“绑定”。如果下拉列表为空，请先确认酒馆已加载对应类型的预设，并且当前扩展运行在 OpenAI / 聊天补全流程中。
5. 绑定后即可切换；点“编辑副本”可以按提示词条目编辑当前角色卡的副本。

> 插件只面向 OpenAI / 聊天补全预设，不负责创建酒馆原预设。应用副本时仍由 SillyTavern 的预设应用流程处理。

插件用于单张角色卡聊天，群组聊天不显示悬浮球。绑定副本的切换和同步仍依赖酒馆原预设存在；请保留原预设名称。

## 编辑角色卡里的预设副本

点击绑定项目上的“编辑副本”会打开条目编辑器。它以酒馆条目列表的方式浏览，而不是让用户直接改一整段 JSON。

1. 在条目列表的搜索框输入名称；需要时点星标按钮，只看收藏条目。
2. 点击列表右侧的滑动开关即可启用或停用条目，可以跨分页、搜索结果连续调整多条开关。点击条目名称后，可在编辑区修改名称、发送身份（系统 / 用户 / 助手）和内容；详情中的开关与列表同步。
3. 点击该条目旁的星标可收藏或取消收藏。收藏是当前浏览器设备的快捷标记；在其他角色卡中，具有相同条目标识的条目也会显示为收藏，方便跨角色快速找到。
4. 点“保存修改”会保存当前条目的内容修改，以及本轮调整过的所有条目开关；改动只写入**当前角色卡的当前绑定副本**。酒馆原预设、其他角色卡和同卡的其他副本都不会因此被改动。

如果在条目中途切换到另一条，尚未保存的内容编辑会先询问是否丢弃；已调整的开关会保留到统一保存或关闭丢弃。保存前把开关或内容改回原值时，不会把它误判成仍有修改。

编辑器先显示条目列表。进入单条编辑后，底部按钮变为“返回”，点击回到列表并保留当前编辑草稿、开关状态、搜索与页码；在列表页点击“关闭”才退出整个编辑器。返回列表不会自动保存，仍需点击“保存修改”。

### “仅编辑”和“完整”模式

在编辑器右上角点问号图标，可以查看说明并切换模式。默认是“仅编辑”。

- **仅编辑：** 可以搜索、收藏并修改条目字段，不显示结构编辑控件，避免误删或误拖。
- **完整：** 在仅编辑能力之外，可以新建条目、删除可编辑条目，并长按拖动手柄调整顺序。按住条目左侧的拖动手柄，再拖到目标位置；不是点一下就会移动。
- **酒馆自动生成的占位条目：** 名称、删除和拖动均受保护；有些占位条目没有可编辑内容。插件不会把这些条目当普通提示词重命名。

预设列表每页最多 8 项，提示词列表默认每页最多 15 项。只有总数超过一页才显示分页栏；分页栏提供上一页、下一页和页码输入跳转。条目搜索或收藏筛选后，分页会按筛选结果重新计算。

点击“编辑副本”右上角的问号，在“条目编辑说明”的“条目分页”中可独立设置：

- **自定义每页条目数**：开启后可填写 1–500 的整数，立即重新分页；关闭后恢复每页 15 条，并保留之前填写的数值。修改数量时会定位到包含原页面第一条的页，不丢弃正在编辑的内容。
- **翻页自动回到顶部**：默认开启，点击上一页、下一页或跳转到其他页后回到条目列表顶部；关闭后尽量保留原滚动位置，新页面较短时受其高度限制。

这两项设置自动记住并跨角色使用，不修改预设内容，也不会让副本显示为已修改。

### 柏宝箱预设分组

支持读取柏宝箱保存在 `extensions.baibaiToolkit.presetPromptGroups` 中的分组。已绑定的旧副本若尚未包含分组，先在酒馆保存带分组的原预设，再在副本上选择“检查 / 同步更新”。

- 条目列表按预设发送顺序显示，给连续属于同一组的条目添加组名、成员数量、折叠按钮和整组开关。未分组条目保留原位置，不会为了分类被搬到一起；同一组在多个位置出现时，各段标题控制同一个组。分页按用户设置的提示词数量计算，跨段或跨页时显示本段和筛选结果中的成员数量。
- 整组停用会保留成员各自的条目开关。组内条目变为弱化显示，详情也会提示“所属分组已停用”。实际生成时的整组控制由已启用预设分组的柏宝箱处理。
- 搜索支持条目名称、标识和组名；搜索或只看收藏时自动展示匹配成员，不必逐组展开。普通列表恢复原折叠状态。
- 分组开关随“保存修改”写入当前角色副本。展开或收起只保存为界面偏好，不改预设数据，也不会产生“副本已修改”状态。完整模式删除条目会清理分组归属；拖到另一组条目旁会加入该组，拖到未分组条目旁会退出分组。
- 切换前优先注入副本，再交给柏宝箱渲染，支持同一来源预设的多个副本具有不同分组和组开关。
- 同步按分组 ID 比较组属性，冲突仍由用户选择处理。此适配针对提示词分组；尚未提供正则分组编辑，也不接管柏宝箱原生页面的预设保存。请从本插件的“编辑副本”修改角色副本；在酒馆原生预设页保存仍属于原预设操作。

柏宝箱新建分组后可能只更新运行设置，尚未写入原预设文件。在当前副本使用中点击“检查 / 同步更新”，若检测到分组有变化，会提供“保存分组到副本”“仅同步原预设”和“取消”。前者只保存分组名称、成员、排序、折叠和组开关到当前角色副本，不保存提示词正文，也不推进原预设的同步基线；后者继续比较酒馆已保存的原预设。若需要所有角色都从原预设同步新分组，请先在酒馆明确保存原预设。

不要求安装柏宝箱才能浏览和保存分组元数据；整组开关的生成效果需要柏宝箱的“预设分组”开启。旧的 `entryGrouping` 格式请先由柏宝箱导入并保存成上述格式，再同步到角色副本。

## 切换预设与 API 设置

切换时是否跟随预设的 API 连接配置，可以在悬浮球面板右上角的外观设置按钮中选择“切换预设时保留当前 API 设置”。

- **开启：** 保留当前 API 来源、模型等连接设置，只应用所选角色卡副本中的预设内容。连接设置字段由酒馆的设置定义标记；`chat_completion_source` 始终会保留。
- **关闭：** 由酒馆按其正常的预设应用流程处理预设数据，包括该预设带有的连接配置。若不同预设指定了不同 API 来源或模型，切换时可能随之变化。

这项设置是全局界面偏好，不属于某张角色卡或某个副本。默认关闭。

## 完整模式与快速模式

外观设置中的“显示模式”只改变悬浮球面板显示内容，不会改动绑定关系或副本。

- **完整：** 显示备注/预设名、同步状态，以及切换、编辑副本、复制副本、备注、检查 / 同步更新和解绑等操作。若副本名与来源预设名不同且没有备注，会额外显示副本名。
- **快速：** 只显示当前角色、备注（如有）、预设名和切换按钮；不会显示编辑、复制、同步或解绑控件，适合日常快速换预设。

## 同步酒馆原预设的更新

酒馆原预设更新后，角色卡副本不会自动覆盖。打开完整模式，点击该副本的“检查 / 同步更新”，由用户决定是否合并原预设的新内容。

同步会比较三份内容：上次同步时的基线、角色卡当前副本、酒馆最新版。

- 只在酒馆一侧修改的字段会合入角色副本。
- 只在角色副本一侧修改的字段会保留。
- 同一字段两侧都改成不同值时，会出现冲突处理界面。使用条目名、组名和中文字段名定位冲突；分别显示角色副本和原预设的最新值，高亮相对上次同步变化的文字，可展开查看上次同步值。点击“保留这一边”或“采用这一边”即可选择结果；也可手动修改或删除字段。文本可直接输入，数字和开关使用对应控件，复杂对象或列表仍需有效 JSON。需要逐项处理全部冲突后才能完成同步。
- 同步成功后，酒馆最新版成为新的比较基线。如果正在使用这个副本，插件会将合并后的副本重新应用。
- 同步只改当前角色卡的副本和它的同步基线，不会把副本内容写回酒馆原预设。

如果提示“与同步基线一致”，表示酒馆**已保存的**原预设还没有变化。请先在酒馆正常编辑并保存原预设，然后再点“检查 / 同步更新”。同步按原预设名称关联；如果原预设被重命名或删除，插件无法自动识别新名字，需要重新绑定。

## 悬浮球和外观

- 可以在“扩展程序 → 预设切换器”里关闭“显示悬浮球”，也可以在设置弹窗中关闭。隐藏悬浮球后，仍可从扩展设置中的“管理角色预设”打开面板，或重新打开悬浮球；隐藏只影响显示，不影响角色副本的应用。
- “显示悬浮球”旁的“界面跟随悬浮球移动”默认关闭：预设切换面板固定在屏幕正中间，拖动悬浮球不会带动面板。开启后面板在悬浮球附近展开并随球移动。扩展设置中切换会立即生效，设置弹窗中则需点击“保存设置”；该选项会记住，抽卡、编辑等原本居中的弹窗保持居中。
- 居中面板使用独立的页面容器，避免悬浮球收纳脚本或主题对悬浮球容器的缩放、位移、滤镜和裁切影响面板位置；悬浮球仍可照常收纳。若使用跟随模式，面板会和悬浮球一起受到收纳容器的布局影响。
- 悬浮球可在聊天页面自由拖动；放在屏幕中间时不会自动吸边。拖到左右屏幕边缘附近后才会贴边，并隐藏一部分以减少遮挡；拖到边缘以外的区域会回到可见位置。页面会记住位置。
- 球面直径默认 40 px，可在设置中用滑块或数字输入调整为 24–80 px，提供尺寸预览和“恢复 40 px”。已保存的自定义大小保持不变。点击“保存设置”后生效；取消不会保存大小。触控区域至少为 48 × 48 px，并随球面增大（直径加 16 px），默认触控区域为 56 × 56 px。所有尺寸贴边时左右都隐藏半个球面。
- 点面板右上角的外观设置按钮可以打开设置弹窗，配置图标和显示模式，不会展开独立的外观面板。
- 默认图标使用当前酒馆地址下的 `favicon.ico`，因此会跟随当前主机和端口。
- 图标支持图片 URL、本地图片文件，也可以把图片文件拖到悬浮球上。浏览器限制本地图片在当前设备保存，文件最大 2 MB；恢复默认图标会重新使用当前酒馆的图标。

启动或重新载入聊天时，插件会检查当前预设是否已经与角色副本一致，一致时不重复选择预设，避免因此再次触发预设正则的刷新提示。真正切换或修改预设时，酒馆正常的正则提示仍然保留。

## 角色抽卡

在酒馆“扩展程序 → 预设切换器”中手动勾选“开启角色抽卡”，开关与“显示悬浮球”并列，默认关闭。关闭时点击悬浮球直接打开预设切换器，不显示抽卡入口；开启后才出现“预设切换器”和“角色抽卡”两张入口卡片。抽卡在未选择角色时、正在与角色聊天时都可打开，也不要求当前使用聊天补全 API。预设管理入口仍需打开角色聊天并使用 OpenAI / 聊天补全。

进入抽卡后可以在“角色”和“预设”之间切换。角色抽卡从本地角色库随机抽取；预设抽卡范围可在右上角设置中选择：默认开启“预设抽卡仅使用当前角色绑定的预设”，在角色聊天时只从该角色已绑定且原预设仍存在的项目中抽取；关闭后，即使正在角色聊天也从酒馆全局 OpenAI / 聊天补全预设中抽取。没有打开角色聊天时始终从酒馆全局预设中抽取。预设结果只显示预设名，不显示图片。每次可抽 1–5 个结果，抽完后点选一个结果，再选择“开玩”或“切换预设”。抽取过程提供短暂动效；系统设置减少动态效果时跳过动效。

角色抽取本身不会切换聊天、发送消息或新建聊天。“开玩”通过酒馆原有角色切换流程打开所选角色聊天，再沿用角色绑定的预设应用逻辑。聊天正在生成或保存时需等待完成。角色聊天内的预设抽取会应用对应角色的专属副本，不修改副本内容；没有打开角色聊天时会切换酒馆全局预设。“切换预设”保留预设切换器已有的 API 设置规则。

右上角齿轮 SVG 打开抽卡设置：

- **每次抽取数量**：1–5 个结果，角色和预设抽卡共用该设置。结果数量大于候选数时，为凑足数量，同一批结果可能出现重复。
- **角色抽卡范围**：全部角色，或仅收藏角色。收藏来自酒馆角色库的收藏标记，与预设条目收藏无关。此范围不影响预设抽卡。
- **预设抽卡仅使用当前角色绑定的预设**：默认开启。在角色聊天中，只从当前角色绑定且来源预设仍存在的预设副本中抽取；关闭后改从酒馆全局 OpenAI / 聊天补全预设抽取。未打开角色聊天时始终从全局预设抽取。抽到绑定预设时应用当前角色的专属副本，抽到全局预设时切换酒馆全局预设。
- **排除当前正在玩的角色**：默认开启；未选择角色时不会排除任何角色。
- **同一轮不重复抽取**：默认开启；本次页面使用期间记录已抽角色，抽完自动开始新一轮。有多张候选时，新一轮第一张避免与上一张重复。刷新页面后记录重新开始，修改抽卡范围或规则也会开始新一轮。

抽卡设置自动保存在当前酒馆的扩展设置中。未开启时，点击悬浮球仍直接打开预设切换器。没有角色候选时会提示更换范围、收藏或导入角色卡；角色聊天中没有绑定预设时会提示先绑定，未进入角色聊天且酒馆没有全局预设时会提示先创建预设。抽到后角色被删除时，“开玩”会提示重新抽取。

## 数据保存与范围

- 每张角色卡的绑定列表、副本内容、备注和同步基线保存在角色卡 `data.extensions.preset_switcher` 中，并随角色卡数据保存。
- 悬浮球位置、大小、图标、显示模式和“保留当前 API 设置”保存在本地酒馆扩展设置中。
- 收藏保存在当前浏览器的 `localStorage` 中，不会写进预设或角色卡，也不会自动同步到其他设备。
- 编辑器按页显示条目，避免几百条提示词一次性铺满界面；搜索、收藏过滤和翻页只更新当前可见列表。
- 渲染状态时，同一轮里按原预设名缓存预设名列表和同步版本读取结果，避免同一个来源被重复读取。这里说明的是实现方式，不代表经过特定设备的性能基准测试。

## 常见问题

**已启用插件，为什么扩展设置里没有“预设切换器”？** 部分旧版 ST 不会调用新版扩展激活钩子。本插件同时提供页面就绪初始化，并防止重复创建界面；请更新插件后重新加载酒馆。若仍然没有这一栏，请提供 ST 版本号和插件加载错误信息，以区分初始化兼容问题与文件加载失败。

**为什么角色列表里没有某个预设？** 只有绑定过的预设才可切换。先在完整模式面板底部绑定；预设选择列表取自酒馆当前可用的 OpenAI / 聊天补全预设。

**为什么检查同步后没有变化？** 插件读取酒馆已保存的源预设。请先保存源预设，再检查；如果源预设确实变化但冲突处理未完成，角色卡副本也还不会保存为新结果。

**复制副本会复制什么？** 新副本从所选副本的当前内容开始，并沿用相同的酒馆原预设作为同步来源。副本名称、备注和条目内容可分别保存；当前使用状态属于这张角色卡，一次只能有一个副本处于使用中。

**解绑会删掉酒馆原预设吗？** 不会。解绑只移除当前角色卡上的这个副本及对应绑定关系；其他角色卡和酒馆原预设不受影响。

**API 来源或模型为什么变了？** 检查“切换预设时保留当前 API 设置”。开启后插件会排除酒馆标记为连接设置的字段，并保留 `chat_completion_source`；关闭时遵循酒馆通常的预设应用行为。
